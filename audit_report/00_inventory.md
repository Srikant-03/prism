### Critical Documentation vs. Reality Discrepancies Detected in Stack
1. **React Version**: README badge and text claim `React 18`. Reality: `frontend/package.json` installs `react: ^19.2.0`.
2. **Graph Visualization**: README claims `node-link relationship diagrams powered by React Flow`. Reality: `react-flow` is **NOT installed** in `package.json`; relationship diagrams are implemented using **Apache ECharts** (`echarts-for-react`).
3. **Single Master API Key**: System claims multi-tenant authentication, but implements a single static string check `DATA_INTEL_API_KEY` (default `change-me-to-a-secure-secret`) baked into frontend environment variables (`VITE_API_KEY`).

## Entry Points and Execution Runbook

### Primary Entry Points
1. **One-Click Boot Script**: `start.bat` (Windows command script)
2. **Backend Server**: `backend/main.py` -> invokes `uvicorn.run('main:app', host=AppConfig.HOST, port=AppConfig.PORT)`
3. **Frontend Application**: `frontend/index.html` -> `frontend/src/main.tsx` -> `frontend/src/App.tsx`
4. **Termination Script**: `stop.bat` -> kills windows named `Prism Backend*` and `Prism Frontend*`

### Installation & Setup Guide (As a New Developer)
```bash
# 1. Clone repository
git clone <repo-url>
cd prism

# 2. Backend virtual environment & dependencies
python -m venv backend/venv
backend/venv/Scripts/pip install -r backend/requirements.txt

# 3. Frontend dependencies
cd frontend
npm install
cd ..

# 4. Configure environment
copy backend/.env.example backend/.env
# Edit backend/.env to configure GEMINI_API_KEY and DATA_INTEL_API_KEY
copy frontend/.env.example frontend/.env

# 5. Launch services
start.bat
# Or run manually in two terminals:
# Terminal 1: cd backend && venv\Scripts\python.exe main.py
# Terminal 2: cd frontend && npm run dev
```
